# Mots-Caches-Cabinet-Celicourt-et-Associes
Découvrez le droit sous un nouvel angle avec l'application officielle Mots Cachés – Cabinet Celicourt et Associés.  Alliant rigueur intellectuelle et divertissement, ce jeu de lettres interactif a été spécialement pensé pour célébrer la culture juridique et mettre en valeur l'univers de la justice.
